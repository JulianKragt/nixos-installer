**Stage 0.1 — Provider preparation.** Runs on the provider, plus read-only checks on the target, which is still the NixOS ISO.

Purpose: be certain everything is in place before anything is wiped, collect the host facts later stages need, get the operator's explicit confirmation, and deliver the LUKS passphrase.

Expects: stage 0.0 has resolved `env.State.Disk`; `env.Host`, `env.Target`, `env.ConfigDir` are set; config prerequisite B1 is done.

Must do:
- Read facts with `nix eval --json <ConfigDir>#installHosts` → primary user, users, configured disk.
- Check the config repo is a git repo with an upstream and has no uncommitted changes outside the paths the installer manages (`hardware-configuration.nix`, `install.json`, `flake.lock`), because only pushed config is installed in Phase 3.
- Write `hosts/nixos/<host>/install.json` when it differs from `State.Disk` and `git add` it (flakes ignore untracked files); confirm `installHosts.<host>.disk` now equals `State.Disk` and that the device is a block device on the target.
- Target checks: `nix` and `lsblk` present, `https://cache.nixos.org/nix-cache-info` reachable.
- Show `lsblk` and the target hostname, then require the operator to type `install`.
- LUKS passphrase from `DISKO_PASSWORD` or asked twice without echo; send it with `RunStdin` to `/tmp/disko-password` (mode 600) on the target.

Introduces shared plumbing:
- A way on `pipeline.Machine` to run a command without streaming its output to the runner and the log file (RUNNER.md asks for this with the first secret command).
- `runner.AskSecret`: a question without echo (RUNNER.md lists it as not built).
- Tool helpers, each in its own package with functions taking a `pipeline.Machine` (not files in `internal/stages`, see CONTEXT §4): `internal/nix` for `nix eval --json`, `internal/git` for git (always `git -C`, commit listed paths only, only when there is a diff).

Writes State: `PrimaryUser`, `Users`.

Legacy reference: Phase 1–2, lines 311–379.
