**Stage 2.3 — Template authoring.** Runs on the target, interactive.

Purpose: every secret file this host needs exists, is encrypted to the current recipients, and holds real values instead of template placeholders.

Expects: 2.2 (rules in place). `docs/ROADMAP.md` "Verified assumptions" says how sops decrypts with the host SSH key on the target.

Must do, per file (`hosts/<host>.yaml`, each `host-users/<host>-<user>.yaml`):
- Decryptable by the host → `sops updatekeys -y` when recipients changed, otherwise nothing.
